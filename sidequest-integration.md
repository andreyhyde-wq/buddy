## Что бы я поменял

**Убрать или не делать**
- Внешнюю загрузку шрифтов с Google Fonts. Положить шрифты рядом с приложением: офлайн с первого запуска, нет зависимости от зарубежного сервиса.
- Не делать аккаунты, пока нет синхронизации. Без неё они ничего не дают (уже проверено на v1).

**Добавить** (в порядке пользы на сцене)
1. **«Свет».** За N минут до конца слота экран меняет цвет и телефон вибрирует. Это замена лампы ведущего, ради неё не нужно смотреть на цифры.
2. **Запись по шуткам.** Сцена уже знает, когда ты переключил шутку. Если сохранять эти моменты, после выступления любую шутку можно прослушать отдельно и оценить на слух, а не по памяти. Этого нет в связке «Заметки + секундомер».
3. **Режим репетиции.** Прогоняешь сет вслух с таймером, и длительность каждой шутки записывается по факту, а не по оценке.
4. **Журнал выступлений.** Где и когда выступал, какой сет, оценки. У шутки видна статистика: «7 раз, 5 плюсов».
5. Позже, с сервером: кнопка «Разобрать» по правилам `buddy_brain.md`. Это платный запрос к нейросети, цену считать перед подключением.

**Осовременить (техника, без изменения вида)**
- Перенести шутки из localStorage (около 5 МБ, данные могут пропасть) в IndexedDB.
- Иконка для Android, которая не обрезается (maskable).
- На Android добавить «Поделиться → БАДДИ», чтобы шутка из «Заметок» сразу попадала в приложение (Web Share Target). На iPhone такого нет.
- Предупреждение для iPhone: Safari может стереть данные сайта, если его не открывать 7 дней. Приложение с экрана «Домой» от этого защищено. Подсказку об установке показывать при первом запуске.
